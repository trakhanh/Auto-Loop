# Trang "Tải video" (yt-dlp) — Kế hoạch triển khai

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Thêm trang "Tải video" vào KT Loop Station: dán link (lẻ / danh sách phát / kênh) → xem trước → tải MP4 về thư mục bằng yt-dlp, công cụ tải được cài lần đầu và tự cập nhật.

**Architecture:** Ba mô-đun lõi không phụ thuộc Qt (`core/dl_tools.py` cài / cập nhật yt-dlp.exe + deno.exe; `core/downloader.py` dựng tham số, đọc JSON, tách tiến độ, chạy tiến trình; `core/download_queue.py` danh sách tải + lưu `downloads.json`), một trang giao diện `ui/download_page.py`, rồi nối vào `MainWindow` (stack chỉ số 6, thanh bên, thẻ Bắt đầu, giữ máy thức, hỏi tải tiếp). yt-dlp chạy như tiến trình riêng, giống FFmpeg.

**Tech Stack:** Python 3.12, PySide6, yt-dlp.exe (kênh nightly), Deno (JS runtime cho YouTube), FFmpeg có sẵn trong `bin\`, pytest.

**Spec:** `docs/superpowers/specs/2026-11-20-tai-video-design.md` — người làm đọc cả spec lẫn kế hoạch.
